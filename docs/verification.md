### 見つけて直したこと

| 止まった箇所 | 原因 | 直し方 |
| --- | --- | --- |
| Python 3.11 で `pip install` が `UnicodeDecodeError` | `requirements.txt` の日本語コメントを、古い pip が日本語 Windows の cp932 で読んでいた | コメントを英語にし、ASCII だけであることをテストで確認 |
| `parent.sh install` が「問題ありません。」の後に `tmp: unbound variable` で失敗扱い | 終了時の後片付けが、関数を抜けた後の変数を参照していた | グローバル変数に変更し、install を最後まで通すテストを追加 |
| MySQL の準備後に「tmux で起動」と案内される | 旧方式の案内が残っていた | `Next: scripts/parent.sh install` に変更 |
| 新規子機の登録画面が「最終通信 9999秒前」、時刻に `GMT` | MySQL が返す日時を、SQLite 時代の文字列として解析していた | 日時をそのまま扱い、表示は `YYYY-MM-DD HH:MM:SS` に統一 |
| 新しい承認 API が、作られたばかりの子機を「期限切れ」として削除 | 同じ原因で、期限の判定が常に「期限切れ」になっていた | 同上。MySQL と同じ日時の値でテストを追加 |
| 運用管理からログアウトへ行くのに URL の手書き換えが必要 | ページに戻るボタンがなかった | 他の管理画面と同じ「管理者メニューに戻る」を追加 |
| 履歴やチケットに `restock`・`jam / open` と表示される | 内部コードをそのまま表示していた | 「補充」「詰まり / 受付」など日本語で表示し、画面例の画像も作り直した |
| 「Python 3.12 系」とだけ書かれ、3.14 の人が進めてよいか判断できない | 基準の書き方があいまいだった | 「3.12 以上」と判断表、`py -3.12` の使い方、pip の `[notice]` は無視してよいことを追記 |
| EUC-JP の Raspberry Pi で子機が止まる恐れ | tmux 起動時の Python が OS の文字コードで出力していた | `venv-start.sh` で `PYTHONUTF8=1` を設定し、確認方法を setup.md に追記 |
