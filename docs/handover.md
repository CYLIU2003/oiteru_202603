# 引き継ぎ票：先輩と最初に埋めるページ

[当番の操作ガイド](../QUICK_START.md) を始める前に、先輩とこの表を埋めてください。
設置先で異なる情報を、記憶や口頭だけに頼らないための用紙です。印刷して使っても構いません。
この見本には実際の URL・担当者・連絡先を記載していません。

## 画面と連絡先

| 項目 | 引き継ぎ時に記入する欄 |
| --- | --- |
| 記入日・確認した先輩 | 未記入 |
| 管理画面の URL（`/admin` まで） | 未定。決まり次第、先輩と記入 |
| 運用管理の URL（`/admin/operations` まで） | 未定。決まり次第、先輩と記入 |
| 画面を開くためのネットワーク・VPN | 未記入 |
| 自分が使う管理者ユーザー名の確認方法 | 未記入 |
| パスワードの安全な受け取り・保管方法 | 未記入。パスワードそのものは記入しない |
| 登録用 PC とカードリーダーの場所 | 未記入 |
| 通常の問い合わせ先（担当・連絡手段） | 未定。決まり次第、先輩と記入 |
| 緊急時・担当者不在時の連絡先 | 未定。決まり次第、先輩と記入 |

記入した内容に学内限定の情報があれば、学内の決められた場所で保管し、公開 GitHub へ追加しません。
パスワード、カード番号、秘密鍵、バックアップ鍵は、この用紙やチャットに書かないでください。

## 担当する子機

| 確認すること | 記入する欄 |
| --- | --- |
| 子機名（画面と実物の表示を合わせる） | 未記入 |
| 子機の起動方法（tmux / systemd） | 未記入。状態確認・停止・復帰の方法も確認する |
| 建物・階・部屋などの設置場所 | 未記入 |
| 補充品の種類・保管場所 | 未記入 |
| 機械を開ける鍵・道具の保管場所 | 未記入 |
| 補充前の利用停止・補充後の再開方法 | 未記入。実機を見ながら確認する |
| 補充できる上限数・向き・並べ方 | 未記入。実機を見ながら確認する |
| 余った用品・破損品の取り扱い | 未記入 |
| 当番日・次の担当者への連絡方法 | 未記入 |

機種ごとの開け方・入れ方はプログラムからは判断できません。
初回に先輩が実物で説明し、写真が必要なら利用者情報や秘密情報が写らないものを学内で保管してください。

## 練習したことを記録する

| 項目 | 確認日・一緒に確認した人 |
| --- | --- |
| 自分でログインし、担当子機を見つけた | 未記入 |
| 実物の補充と、追加数の記録を行った | 未記入 |
| 「直近の在庫操作」で保存結果を確認した | 未記入 |
| 保存が不明なときに、二重登録せず確認する流れを説明した | 未記入 |
| 故障時のメモと連絡方法を説明した | 未記入 |
| 利用者の登録・タッチ・受け取りを体験した | 未記入 |
| ログアウトした | 未記入 |

わからなかった言葉や止まった箇所も記録し、説明書を直す材料にします。
後輩が実際に一連の操作を行うまでは、「読めば必ずできる」と扱わないでください。
