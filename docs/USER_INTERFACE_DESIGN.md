# 画面の設計方針

オイテルの画面は Flask と Jinja で描画します。[デジタル庁デザインシステムの React 実装例](https://github.com/digital-go-jp/design-system-example-components-react) の Button、NotificationBanner、ナビゲーション、入力欄の設計を参照し、既存のテンプレートと CSS に適用しています。参照時点はコミット `e637c68` です。

- 管理者は業務トップから、在庫・保守、子機監視、利用者対応へ移動する。ログイン中は共通ナビゲーションからも移動できる。
- 利用者はホームから登録または利用状況の確認へ進む。各画面で次の操作を明示し、失敗時は再試行や戻り先を用意する。
- 状態は色に加えて文字で示す。入力にはラベルと補足情報を関連付け、キーボードで操作中の位置を視覚的に示す。
- 既存のサーバールート、カード処理、認証、子機APIを利用する。画面の変更と端末制御の変更は別の差分で管理する。
